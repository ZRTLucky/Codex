# 加密模型预览

PC 本地加密，浏览器下载密文后解密显示。当前包只含无工程数据的测试方块，没有渔轮模型或原始 CAD。

- 一个 GLB 保留零件层级和运动轨迹，支持按钮切换状态、拖动进度、往返播放以及旋转缩放。
- 模型和目录用 AES-256-GCM 加密；访问密钥单独提供，不存放在仓库或 URL 中。
- 页面、解码器和加密文件可通过 GitHub Pages 同源提供；静态文件根目录用于发布。
- 这是浏览器本地解密，不是服务端账号登录；已取得密文与密钥的人仍可继续解密旧包。
- 本地验证通过不代表用户手机的下载速度或公网访问已经验证。

更新时使用本机 cad-remote-preview SKILL：明确选择 GLB、生成新的随机密钥与加密包、运行验证、检查暂存文件，再上传指定输出。不要提交输入清单、原始模型、明文缩略图、访问密钥或本机记录。

访问者只需打开配置后的 HTTPS 页面，粘贴另行收到的访问密钥。密钥不随下载请求发送。
