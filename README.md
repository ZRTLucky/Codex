# 加密装配联动预览

当前测试包包含指定的131版离合装配网格及采样运动轨迹，保存在加密GLB包内。原始STEP、SolidWorks、密码和构建记录不在仓库中。

- 一个模型支持抬起／下降按钮、任意进度、播放暂停和旋转缩放。重复点击当前装配不会重置或隐藏控制区。
- 装配名称、多个联动项目、起终点按钮和读数标签由加密目录配置，支持后续加入齿轮等联动；当前只提供已建好的离合轨迹。
- 模型和目录使用随机AES-256-GCM密钥加密；可由另行获知的访问密码在浏览器内解锁。密码保护采用PBKDF2-SHA256（600000次迭代）包裹随机数据密钥。
- 密码不随网络请求发送；未勾选记住时不保存。勾选记住此设备后，仅在当前浏览器IndexedDB保存不可导出的解密凭据，可用忘记此设备删除。
- 主动锁定会阻止当前会话刷新后自动进入；更换浏览器、清除站点数据或更换加密包后可能需要重新输入密码。
- 静态加密不能撤回已经下载并解密的数据，也不构成防复制或连续无干涉证明。

页面和加密文件通过GitHub Pages同源分发。用户手机的实际网络速度与交互效果以手机实测为准。第三方组件见THIRD_PARTY_NOTICES.txt。
